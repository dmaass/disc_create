# disc_create v1.0 source

## Deutsch

- `make_floppy.py` — Disketten-/Span-/ISO-Kommandozeilenwerkzeug
- `make_iso.py` — eigenständiges ISO-Kommandozeilenwerkzeug
- `ui.py` — Desktop-UI (`python ui.py`)
- `config.py`, `contextmenu.py`, `lang.py`, `dnd.py` — Einstellungen,
  Kontextmenü, Sprachen, Drag & Drop (werden von der UI genutzt)
- `tests/` — unittest-Suite: `python -m unittest discover -s tests -v`
- `build_exe.bat` — `disc_create.exe` neu bauen (braucht Python + pip)

Keine Drittabhängigkeiten. Vollständige Doku siehe `../README.md`.

## English

- `make_floppy.py` — floppy / span / ISO command-line tool
- `make_iso.py` — standalone ISO command-line tool
- `ui.py` — desktop UI (`python ui.py`)
- `config.py`, `contextmenu.py`, `lang.py`, `dnd.py` — settings,
  context menu, languages, drag & drop (used by the UI)
- `tests/` — unittest suite: `python -m unittest discover -s tests -v`
- `build_exe.bat` — rebuild `disc_create.exe` (needs Python + pip)

No third-party dependencies. See `../README.md` for full docs.
